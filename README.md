# Advanced Movie App

This is a movie discovery app I built using HTML, CSS, and Vanilla JavaScript.

I created this project to practice my JavaScript skills, especially working with APIs, asynchronous functions, DOM manipulation, and building dynamic user interfaces.

The app uses the TMDB API to get movie information.

## Features

- Search for movies by title
- Browse trending movies
- Filter movies by genre and year
- Sort movies by different options
- View movie details
- Load more movies with pagination
- Switch between dark and light mode
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- Vanilla JavaScript
- TMDB API

## What I Learned

While building this project, I practiced working with `fetch`, `async/await`, API responses, and JavaScript events.

I also learned more about organizing JavaScript code, handling errors, and updating the page dynamically without reloading it.

## About This Project

This is one of the projects I built while learning frontend development.

My goal was to create something more advanced than my previous JavaScript projects and improve my ability to build real applications.
